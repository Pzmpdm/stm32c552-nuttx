# STM32C552VET6 DevKit Core 六阶段适配计划

> 使用现有 NuttX STM32C5 端口、NuttX Apps、CMake/Ninja、GNU Make 和 Renode Robot Framework。每个独立功能在回归通过后本地提交，并记录仿真与真机的证据。

**目标**　交付可维护的板级支持包。板载接口和选定的扩展接口各自具备可用的 NuttX 驱动入口、可重现的构建和实测记录。

**基线**　NuttX `336d3854`，NuttX Apps `d14111eb`，板级配置 `stm32c552vet6-devkit:nsh`。USART1 使用 H4 的 PA9/PA10、115200 8N1。现有固件使用 48 MHz HSIDIV3、64 KiB SRAM1，保留 Flash 起址 `0x08000000`。见 [NSH 验收计划](2026-11-06-stm32c552-nsh.md)。

## 1. 启动和 NSH

- [x] Renode 运行 `renode/nsh.robot` 与 `renode/nsh-regression.robot`。验收复位向量、串口寄存器、`sleep 1`、诊断命令、临时文件与脚本、100 轮资源回收。基线六项通过。
- [ ] 用同一份通过仿真的固件做实体板烧录读回、10 次断电启动、10 次 NRST、100 条带序号的命令和 30 分钟运行。归档固件哈希、烧录与串口记录。
- [x] 保留 USART1 作为后续阶段的诊断入口。实体板验收单独记录。

## 2. 板载 LED 和按键

- [x] 在板级 Kconfig、`include/board.h`、`src/` 和 `configs/nsh/defconfig` 中加入标准用户 LED 和按键 lower-half。PH3 驱动低电平点亮的 LED2，PC13 配置内部上拉并检测 SW2 的双边沿。板级提交为 `a838abd0`。
- [x] 以 `/dev/userleds`、`/dev/buttons` 为接口，复用 NuttX Apps 的 `leds`、`buttons`。Renode 接入 GPIOC、GPIOH 和 EXTI13（NVIC IRQ 20），用 `renode/gpio.robot` 验证初始灯灭、亮灭切换、按下/松开的两轮中断通知，再跑 NSH 回归。CMake 和 GNU Make 各八项通过。
- [ ] 实体板确认 LED 极性和按键电平，观察机械抖动。记录 H2/H3/H4 已占用的信号和后续外设复用冲突。

## 3. SRAM2 和时钟

- [x] 核对 RM0522、AN5342 和 ES0661。保留 option-byte 的现有 ECC 状态，先开 SRAM2 时钟，再用对齐的 32 位写入清零，最后注册独立堆区。初始堆留在 SRAM1。板级提交为 `cf0d9f10`。
- [x] Renode 将两块 SRAM 分开建模。冷启动和复位测试均检查清零。通过 60,000 字节的分配、地址范围、8 位及 32 位读写、释放和堆容量检查。CMake 与 GNU Make 各 10 项通过。
- [x] 保留 48 MHz 基线，加入 `nsh-hse`。正常走 8 MHz HSE 派生的 144 MHz PSI，HSE/PSI 就绪或 PSIS 切换超时时走 144 MHz HSIS。CMake 与 GNU Make 各 4 项时钟测试通过。板级提交为 `bc24ef0c`。
- [ ] 真机读取当前 option bytes，验证 SRAM2 首次访问、ECC、全区模式、冷启动及 NRST。对高速配置实测晶振和波特率。
- [ ] LSE 与 RTC 单独验收。ES0661 指出 LQFP 封装的 PC13 跳变可干扰 LSE。先选定 LSI 或停用 PC13 按键的 LSE 配置，再验收测频和跨复位行为。

## 4. 排针外设和 DMA

- [x] 首个子项 TIM2_CH1 PWM，PA0 AF1（H2.3），标准 `/dev/pwm0` 与 `nsh-pwm` 配置，板级提交 `83519d96`。CMake 和 GNU Make 各通过 14 项 Renode 测试，含六项 PWM 测试和八项 NSH/GPIO 回归。覆盖所列 1 Hz～10 kHz / 1%～99% 测试点、关闭和重新打开。模型 UG 装载补齐及剩余限制见 [PWM 记录](../../PWM.md)。真机验收待完成。
- [x] 第二个子项 USART2，TX PA2 / RX PA3 AF7（H2.1/H2.6），标准 `/dev/ttyS1` 与 `nsh-uart` 配置，板级提交 `31a24fec`，保留 USART1 控制台及 PWM。CMake 和 GNU Make 各通过 19 项 Renode 测试，含五项 USART2 与全部 NSH/GPIO/PWM 回归。覆盖 4 KiB 二进制收发及回环、三组波特率与关闭重开。详细边界见 [USART2 记录](../../UART.md)，实板验收待完成。
- [x] 第三个子项 I²C1，SCL PB8 / SDA PB9 AF4（H3.21/H3.20），标准 `/dev/i2c1` 与 `nsh-i2c` 配置，板级提交 `f2d061f7`。CMake 和 GNU Make 各 27 项通过，含八项 I²C 与全部 NSH/GPIO/PWM/UART 回归。覆盖重复起始、连续写入、256 字节读取、NACK、IRQ 超时恢复与 BERR 勘误注入。时序、外部上拉及模型限制见 [I²C1 记录](../../I2C.md)，实板验收待完成。
- [x] 第四个子项 SPI1，SCK PA5 / MISO PA6 / MOSI PA7 AF5，GPIO CS PA4，标准 `/dev/spi1` 与 `nsh-spi`，板级提交 `1bb4a68e`。复用并公共化 H5 CFG1/CFG2 驱动，补齐 32 位轮询路径。CMake 和 GNU Make 各 36 项通过，新增九项 SPI 并保留此前 27 项回归；覆盖多位宽、mode 0–3、分频、超过 FIFO 的载荷及片选边界。模型补齐和实板限制见 [SPI1 记录](../../SPI.md)。随后完成 ADC1_IN8 PC0。
- [x] 第五个子项 ADC1_IN8，PC0（H3.14），标准 `/dev/adc0` 与 `nsh-adc`，板级提交 `5bcb29fe`。12 位软件触发，转换中断送数。CMake 和 GNU Make 各 43 项通过，新增七项 ADC 测试，覆盖可变输入、单次打开的重复采样、IRQ 及初始化超时恢复。详见 [ADC1 记录](../../ADC.md)。下一子项为 LPDMA。
- [ ] 对每个外设先从 H2/H3 原理图选定一组可用引脚，记录 AF、IRQ、RCC 和复用冲突，再核对 C5 公共驱动的 IP 版本。顺序为 TIM/PWM、额外 UART、I²C、SPI、ADC，最后按需要接入 LPDMA。
- [ ] Renode 对有兼容模型的外设分别验证 PWM 周期和占空比、UART 回环、I²C 读写与 NACK、SPI 传输与片选、ADC 对已知输入的转换，以及 DMA 完成与错误中断。为缺模型的外设记录缺口，避免只用固定返回值判定驱动通过。
- [ ] 实体板用逻辑分析仪、回环、已知参考电压和实际从设备核对波形和错误恢复。每个驱动独立通过构建和 NSH 回归。

第一组排针配置候选如下，启用前继续核对复用冲突和电气条件。

| 外设 | 信号和候选位置 |
|---|---|
| TIM2_CH1 PWM | PA0 AF1，H2.3 |
| USART2 | TX PA2、RX PA3，AF7，H2.1、H2.6 |
| I²C1 | SCL PB8、SDA PB9，AF4，H3.21、H3.20 |
| SPI1 | SCK PA5、MISO PA6、MOSI PA7，AF5，H2.8、H2.7、H2.10。PA4（H2.5）做 GPIO 片选 |
| ADC1_IN8 | PC0 模拟输入，H3.14 |

## 5. USB-C 设备

- [ ] 核对板载 USB-C 的 D+/D−、VBUS 处理、设备角色及 USB 48 MHz 时钟路径。接入 STM32C5 USB FS 设备控制器，首个类为 CDC ACM，保留 USART1。
- [ ] 有兼容控制器模型时，用 Renode 验证复位、端点初始化、枚举和双向传输。真机连接主机验证多次拔插、重新枚举和传输恢复，记录枚举与串口日志。

## 6. 存储、恢复和扩展

- [ ] 先确定 Flash 分区和固件边界，再接入 MTD 和选定的文件系统。用仿真检查越界保护与重挂载，用真机验证擦除/写入和断电恢复。
- [ ] 分开适配 IWDG 和低功耗。仿真验证 watchdog 重启路径与日志；真机验证复位原因、唤醒后时钟恢复及功耗。确有 CAN FD 需求时，在独立外部收发器和终端条件下接入 FDCAN，测试内部回环和实际总线错误恢复。
  CAN FD 可先评估 FDCAN1 RX PB5（H3.24）、TX PB6（H3.23），均为 AF9。

每阶段记录使用的模型、ELF、Robot 报告和实体板状态。仿真替代模型仅覆盖明确测试的行为。
